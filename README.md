# 🌾 3D Ферма (3D Farm Simulator)

Красочный, динамичный и уютный трёхмерный симулятор фермы в стиле Hay Day, созданный на **React**, **Three.js** и **TypeScript**.

---

## ✨ Основные возможности игры

### 🚜 1. Сельское хозяйство и агрономия
- **Быстрое свайп-земледелие:** Посадка и сбор урожая непрерывным движением курсора (свайпом) по грядкам.
- **Множество культур:** Пшеница, кукуруза, морковь, помидоры, сочные тыквы, сахарный тростник, хлопок и др.
- **Сад и деревья:** Яблони, вишни, апельсиновые деревья, персики, какао и ягодные кусты.
- **Непрерывный режим стройки:** Быстрая застройка полей и дорожек в один клик без повторного открытия магазина.

### 🐮 2. Животноводство и питомцы
- Загоны для кур, коров, свиней и овец с индивидуальным поведением животных (прогулки, клевание, анимация дыхания и сбор яиц, молока, бекона и шерсти).

### 🥖 3. Ремесло и производство
- **Кормовая мельница:** Двухъярусная мельница с вращающимися ветряными парусами.
- **Купольная каменная пекарня:** Горящий анимированный очаг, верстак пекаря и свежевыпеченный хлеб.
- **Мастерские:** Маслобойня, сахарный завод, гриль-барбекю, ткацкий станок, пресс для сока и печь для пирогов.

### 🚚 4. Торговля и городские заказы
- **Доска заказов и грузовичок:** Стильный ретро-пикап забирает заказы и уезжает в город через деревянный мост и горные туннели.
- **Придорожный магазин:** Продажа излишков продукции на местном рынке.

### 🎣 5. Рыбалка у реки
- Деревянный пирс с пришвартованной лодкой, удочкой, поплавком, ведром с рыбой и ящиком снастей. Ловите редкие виды рыб разного веса!

### 🌲 6. Живой мир, физика природы и погода
- **3D Волна и Река:** Органически изгибающаяся река с динамическими шейдерными 3D-волнами и горным водопадом.
- **Колыхание деревьев:** Реалистичная физика колыхания крон деревьев и кустарников на ветру.
- **Погодные явления:**
  - ☀️ **Солнечно / Ясно:** Тёплые лучи и летящая цветочная пыльца.
  - 💨 **Ветрено и Листопад:** Вихри осенних листьев, ускорение работы мельниц на +50%.
  - 🌧️ **Тёплый дождь:** Струи дождя, ускорение роста растений на +50%.
  - ⛈️ **Летняя гроза:** Сильный ливень, ускорение роста растений на +80%.
  - ❄️ **Мягкий снегопад:** Падающие снежинки и двойной опыт (+100% XP).
  - 🌫️ **Утренний туман:** Полупрозрачная дымка над рекой, улучшающая клёв рыбы.
- **Времена года по реальному календарю:**
  - 🌸 **Весна:** Март, Апрель, Май (розовые лепестки сакуры).
  - ☀️ **Лето:** Июнь, Июль, Август (сочная зелень и золотая пыльца).
  - 🍂 **Осень:** Сентябрь, Октябрь, Ноябрь (оранжевая листва и тыквы).
  - ❄️ **Зима:** Декабрь, Январь, Февраль (снежные шапки на крышах и мороз).
  - Возможность в любой момент переключить любой сезон или погоду вручную!

## 🛠️ Стек технологий

* **Frontend:** [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
* **3D Графика:** [Three.js](https://threejs.org/) (Low-Poly процедурная генерация, кастомные BufferGeometry, шейдеры)
* **Сборщик:** [Vite](https://vitejs.dev/)
* **Стейт-менеджер:** [Zustand](https://github.com/pmndrs/zustand) + LocalStorage персистентность
* **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
* **Иконки:** [Lucide React](https://lucide.dev/)
* **Звуки:** Web Audio API (звуковой синтезатор без внешних тяжелых mp3)

## 🚀 Инструкция по установке и запуску

### 1. Требования
Убедитесь, что на вашем компьютере установлен **Node.js** версии 18 или выше (проверить: `node -v`).

---

### 2. Клонирование репозитория
Склонируйте репозиторий на свой компьютер:
```bash
git clone https://github.com/lirns200/ferma-top-1-rf-zov-A4.git
cd ferma-top-1-rf-zov-A4
```

---

### 3. Установка зависимостей
Установите необходимые пакеты через npm:
```bash
npm install
```

---

### 4. Запуск сервера разработки
Запустите локальный сервер:
```bash
npm run dev
```

После запуска в терминале появится ссылка (обычно `http://localhost:3000` или `http://localhost:3001`).  
Откройте её в любом современном браузере (Chrome, Edge, Firefox, Safari).

---

### 5. Сборка для публикации (Production)
Для сборки оптимизированного проекта:
```bash
npm run build
```
Готовые файлы будут сгенерированы в папке `dist/`.

## 🎮 Управление в игре

* **Перемещение камеры:** Зажмите левую или правую кнопку мыши и двигайте курсор (или свайпайте пальцем на сенсорном экране).
* **Приближение / Отдаление (Зум):** Вращайте колёсико мыши или используйте жест щипка (pinch-to-zoom).
* **Посадка культур:** Нажмите на готовую грядку -> выберите растение -> проведите по другим грядкам для быстрой посадки.
* **Сбор урожая:** Нажмите на созревшую грядку -> выберите серп -> проведите по урожаю.
* **Строительство:** Откройте магазин (иконка молотка внизу) -> выберите грядку/здание/дерево -> кликните по свободной клетке на ферме.
* **Смена погоды и сезона:** Нажмите на плашку сезона в левом верхнем углу экрана (под полоской опыта).
